# Psychology LMS

Полноценная LMS-платформа для продажи и прохождения онлайн-курсов.

Проект разработан на Django и PostgreSQL. Основной акцент сделан на серверной бизнес-логике, разграничении доступа, обработке платежей, 
работе с приватными материалами и отслеживании прогресса пользователей.

## Возможности

### Пользователи и доступ

* регистрация и авторизация пользователей;
* кастомная модель пользователя;
* разграничение прав доступа;
* отдельная административная роль;
* модерация пользовательских документов;
* ограничение доступа к платным материалам.
* разграничение прав доступа через группы `can_buy_courses` и `admin`;
* предоставление возможности покупки курсов только пользователям с группой `can_buy_courses`;
* отдельная административная группа `admin` для обработки заявок и проверки результатов тестирования;

### Курсы

* создание курсов;
* разделение курса на модули и уроки;
* переиспользование модулей и уроков в разных курсах;
* задание порядка модулей и уроков независимо для каждого курса;
* отслеживание прогресса пользователя;
* автоматическое определение доступных материалов;
* защита приватного контента на стороне backend.

### Переиспользование учебного контента

Модули и уроки представлены как отдельные сущности и не привязаны жёстко к одному курсу.

Связи `CourseModule` и `ModuleLesson` используются для формирования структуры курса и определения порядка элементов.

Это позволяет:

* использовать один модуль в нескольких курсах;
* использовать один урок в нескольких модулях;
* формировать разные курсы из существующего набора учебного контента;
* задавать собственный порядок модулей и уроков в каждой структуре без дублирования самих сущностей.

### Платежи

Для оплаты курсов реализована интеграция с **YooKassa**.

Реализовано:

* создание платежа;
* перенаправление пользователя на страницу оплаты;
* сохранение информации о платеже;
* обработка webhook;
* проверка статуса платежа;
* проверка суммы и валюты;
* проверка связанных `user_id` и `course_id`;
* выдача доступа к курсу после успешной оплаты;
* обработка ошибок платёжного API;
* защита от повторной обработки одного платежа.

### Административная часть

Для управления проектом используется Django Admin.

Администратор может:

* управлять пользователями;
* управлять курсами, модулями и уроками;
* просматривать платежи;
* обрабатывать пользовательские заявки;
* принимать или отклонять документы;
* управлять доступом пользователей.

```text
Psychology_LMS/
│
├── access/          # Проверка прав доступа и защищённые ресурсы
├── accounts/        # Пользователи и аутентификация
├── courses/         # Курсы, модули, уроки
├── progress/        # Прогресс обучения

│
├── Psychology/      # Настройки Django
├── nginx/            # Конфигурация Nginx
├── tests/            # Тесты
│
├── conftest.py
├── database_dump.sql
├── manage.py
├── Dockerfile
├── docker-compose.yml
├── requirements.txt
└── pytest.ini
```

## Работа с доступом к материалам

Приватные материалы курсов не отдаются пользователю напрямую по публичному URL.

Перед предоставлением защищённого файла backend проверяет наличие необходимых прав доступа.

Таким образом, пользователь не может получить платный материал только благодаря знанию URL файла.

## Работа с платежами

Упрощённая схема оплаты:

```text
Пользователь
     │
     ▼
Создание платежа
     │
     ▼
YooKassa
     │
     ▼
Оплата
     │
     ▼
Webhook
     │
     ▼
Проверка платежа
     │
     ├── статус
     ├── сумма
     ├── валюта
     ├── user_id
     └── course_id
     │
     ▼
Выдача доступа к курсу
```

## Тестирование

Перед запуском тестов установите в .env:

PAYMENT=True

Для тестирования используется `pytest` и `pytest-django`.

Тестами покрываются основные бизнес-сценарии проекта:

* аутентификация;
* доступ к курсам;
* доступ к урокам;
* изменение прогресса;
* создание платежей;
* проверка платежей;
* обработка webhook;
* административные действия;
* проверка прав доступа.

Запуск тестов:

```bash
pytest
```

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/Mint1r/Psychology_LMS.git
cd Psychology_LMS
```

### 2. Создание `.env`

Создайте файл `.env` на основе `.env.example`.

Также необходимо указать параметры интеграции YooKassa и SMTP, настроить уведомления.

### 3. Запуск через Docker

```bash
docker compose up --build
```

### 4. Создание администратора

```bash
docker compose exec django python manage.py createsuperuser
```

После запуска приложение будет доступно по адресу:

```text
http://localhost
```


## Дамп базы данных

В репозитории присутствует дамп PostgreSQL базы данных:

```text
database_dump.sql
```

Дамп содержит структуру базы данных и подготовленные данные для локального запуска и проверки проекта.

Дамп базы данных автоматически загружается при первоначальном создании PostgreSQL-контейнера.

Дамп предназначен для удобной проверки проекта без необходимости вручную создавать и заполнять все сущности через административную панель.

Тестовый пользователь:
username: root
password: root

## Переменные окружения

Основные параметры проекта не хранятся непосредственно в исходном коде.

Используются переменные окружения для:

* Django `SECRET_KEY`;
* режима `DEBUG`;
* разрешённых hosts;
* PostgreSQL;
* YooKassa;
* SMTP;
* других внешних сервисов.
* настройки работы интеграций.

Реальные credentials не включены в репозиторий.

Также в переменных окружения настриваются параметры, влияющие на работу приложения: 

* PAYMENT False / True;
* EMAIL_MESSAGES False / True;
* VK_MESSAGES False / True;

В режиме PAYMENT = False не вызывается редирект на страницу платежного агрегатора
